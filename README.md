# Snapshot

Windows 10 及 Windows 11 截图原型。启动后驻留系统托盘。

## 使用

1. 按 `Ctrl+9`，移动鼠标预选窗口、界面控件或有清晰分隔线的内容区，框角会显示选区的像素尺寸。左键单击锁定预选区域，或按住左键拖出自由选区。
2. 锁定后拖动选区内部可移动，拖动任意边线可调整对应的边，拖动四角可同时调整两条边。右键清除当前选区，回到自动预选，再按一次右键退出。
3. 按 `Enter` 或 `Ctrl+C` 复制图片，按 `Ctrl+S` 另存为 PNG，按 `Esc` 退出截图。双击选区也可复制。
4. 在托盘右键菜单中选择「退出」结束程序。

启动截图时所在显示器的左下角只显示当前模式的操作提示，每行左侧是按键，右侧是功能。锁定选区后，鼠标在框内或正在拖动选区时会显示带十字定位线的 5 倍放大镜。放大镜默认在指针右下，贴近显示器边缘时自动换边。

锁定选区后，右下角会出现图标工具栏。左侧从左到右是矩形（`Ctrl+1`）、文本（`Ctrl+2`）、画笔（`Ctrl+3`）、马赛克（`Ctrl+4`）、撤回（`Ctrl+5` 或 `Ctrl+Z`）、重做（`Ctrl+6`、`Ctrl+Y` 或 `Ctrl+Shift+Z`）。撤回和重做每次处理一笔或一次文本编辑、样式修改、变换。右键或再次选择当前工具可退出标注。

- 画笔用左键自由绘制，参数面板可调粗细、选颜色。马赛克跟着圆形光标涂抹，参数面板可独立调笔刷直径和像素块大小。滚轮可以快速调整画笔和马赛克粗细。
- 文本可单击或拖出透明文本框，参数面板可调字号和颜色。创建后就可以拖边缘移动、拖四角缩放或拖上方圆点旋转。按 `Ctrl+Enter` 确认输入，按 `Esc` 退出输入。单击已有文本框可再次选中，双击编辑。

右侧工具栏可截长图、复制（`Ctrl+C`）、选择位置保存 PNG（`Ctrl+S`）或贴图（`Ctrl+T`）。贴图保持在前台，可用左键拖动，滚轮缩放，`Ctrl+滚轮` 调整透明度，右键或双击关闭。

长截图适合网页正文、聊天记录和文档。框住会滚动的内容，给预览面板留一点空间，点击「长截图」图标或按 `Ctrl+7`。蓝色选框固定在屏幕上，框内的上下滚轮可以继续操作原窗口。选区旁会实时预览已拼好的长图，复制和保存与普通截图共用键位，默认是 `Ctrl+C` 和 `Ctrl+S`。右键或按 Esc 回到原选框。滚动太快导致预览停住时，往回滚一些，让前后两屏重新重叠。

## 快捷键

右键点击托盘图标并选择「设置」，点击对应输入框后按键，或直接输入 `Ctrl+Shift+F10` 这样的组合。可以修改全局截图键、工具栏快捷键和贴图不透明度步长。步长默认为每格滚轮 5 个百分点，可设为 1 到 100 的整数。贴图不透明度最低为 15%。保存后立即生效，也可以恢复默认。配置保存在 `%LOCALAPPDATA%\Snapshot\shortcuts.txt`，首次运行会读取旧的 `hotkey.txt` 作为全局截图键。

## 构建

```powershell
cargo build --release --locked
.\target\release\snapshot.exe
```

界面图标基于 [Phosphor Regular](https://phosphoricons.com/)，许可见 [licenses/phosphor.txt](licenses/phosphor.txt)。马赛克使用 Snapshot 的棋盘格图标。
