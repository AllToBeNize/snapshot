# Snapshot

Windows 10 及 Windows 11 截图原型。启动后驻留系统托盘。

## 使用

1. 按 `Ctrl+9`，移动鼠标预选窗口或应用暴露的界面控件。左键单击锁定预选区域，或按住左键拖出自由选区。
2. 锁定后拖动选区内部可移动，拖动任意边线可调整对应的边，拖动四角可同时调整两条边。右键清除当前选区，回到自动预选。
3. 按 `Enter` 或 `Ctrl+C` 复制图片，按 `Ctrl+S` 另存为 PNG，按 `Esc` 退出截图。双击选区也可复制。
4. 在托盘右键菜单中选择「退出」结束程序。

截图快捷操作显示在启动截图时所在显示器的左下角。锁定选区后，鼠标在框内或正在拖动选区时会显示带十字定位线的 5 倍放大镜。放大镜默认在指针右下，贴近显示器边缘时自动换边。

锁定选区后，下方工具栏从左到右是矩形（`Ctrl+1`）、文本（`Ctrl+2`）、画笔（`Ctrl+3`）、马赛克（`Ctrl+4`）、撤回（`Ctrl+5`）、重做（`Ctrl+6`）。再次选择当前工具可退出标注。马赛克用左键拖出要像素化的区域。文本可单击建立默认文本框，或拖出文本框，输入后用 `Ctrl+Enter` 确认、`Esc` 放弃。

右侧工具栏可复制（`Ctrl+C`）、选择位置保存 PNG（`Ctrl+S`）或贴图（`Ctrl+T`）。贴图保持在前台，可用左键拖动，滚轮缩放，`Ctrl+滚轮` 调整透明度，右键或双击关闭。

## 快捷键

在托盘右键菜单中选择「编辑快捷键配置」，或打开 `%LOCALAPPDATA%\Snapshot\hotkey.txt`。文件只需一行，例如 `Ctrl+Shift+F10`。支持组合 Ctrl、Alt、Shift、Win，配合字母、数字或功能键 F1 到 F24（F12 为系统保留键）。保存为 UTF-8，退出再启动后生效。

## 构建

```powershell
cargo build --release --locked
.\target\release\snapshot.exe
```
